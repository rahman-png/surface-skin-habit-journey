# Surface Skin Habit — local homepage mockup

This folder now contains the homepage based on page 1 of `ssh website refreshment-jun.pdf`. The remaining PDF pages have not been implemented yet.

Run `node server.cjs` in this folder and open http://127.0.0.1:4178/. No dependency installation is required.

Photos are local copies sourced from the official Surface Skin Habit website. The top two hero panels begin in monochrome and shift to full colour on hover. The header menus, search within the homepage, testimonial and doctor controls, FAQ tabs and accordions work locally. The newsletter form shows a local mockup message and does not transmit data. Links to pages outside the homepage are mapped to relevant homepage sections until those pages are built.

The previous animated landing page remains recoverable in Git history. These changes are local and have not been pushed to the live GitHub Pages website.
